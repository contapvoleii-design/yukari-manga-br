# Yukari Manga BR

Versão web independente, em português e adaptada para celular.

## Como publicar
1. Abra **Settings → Pages** no GitHub.
2. Em Build and deployment, selecione **Deploy from a branch**.
3. Escolha a branch **main** e a pasta **/(root)**.
4. Salve e aguarde a publicação.

## Recursos atuais
- Interface responsiva em português.
- Leitura de imagens locais selecionadas no aparelho.
- Navegação entre páginas.
- Abertura de links externos em nova aba.

## Limitações
Sites externos podem impedir que seus capítulos sejam exibidos dentro de outro site. A abertura do link não significa que o capítulo foi traduzido. Tradução automática online e integração com fontes ainda precisam ser implementadas.

Este é um projeto independente e não oficial. O Yukari original é um leitor para Windows: https://github.com/Yukari-App/Yukari
